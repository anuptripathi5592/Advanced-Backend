# Advanced-Backend

Backend development practice project using Node.js, Express.js, and Docker.

## Technologies Used
- Node.js
- Express.js
- Docker

## How to Run
1. Clone the repository.
2. Install dependencies using 
pm install.
3. Start the server using 
ode index.js.
4. Open http://localhost:5000 in your browser.

## Response
The server returns a JSON message when accessed.
